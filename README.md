# 효율적인 실무적 게임 프로젝트 관리 방법

게임 프로젝트를 팀으로 진행하면서 정리한 관리 방법이다. 리더와 팀원의 역할, 게임 개발에 맞춘 애자일 운영, 그리고 실제로 쓰고 있는 GitHub Projects 일정 관리 환경까지 담았다.

## 읽는 순서

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | [효율적인 실무적 게임 프로젝트 관리 방법](0_효율적인%20실무적%20게임%20프로젝트%20관리%20방법.md) | 리더의 역할(방향 설정, 그레이존 작업, 갈등 조율, 동기부여)과 팀원의 역할 |
| 2 | [애자일 개발론](애자일%20개발론.md) | 워터폴과 애자일, 스크럼, 칸반, 게임 특화 실천법, 우리 팀 운영 규칙 |
| 3 | [바이브코딩](바이브코딩.md) | AI로 병렬 개발할 때 지킬 것 |
| 4 | [GitHub Projects 일정 관리](GitHub_Projects_일정관리_공유/README.md) | GitHub Projects 보드를 Claude Code 스킬로 운영하는 사례, 세팅 방법, 스킬 템플릿 |

1~3은 읽기만 하면 되는 문서이고, 4는 자기 팀에 같은 환경을 만들고 싶을 때 따라 하는 자료다.

## 폴더 구성

```
├── 0_효율적인 실무적 게임 프로젝트 관리 방법.md
├── 애자일 개발론.md
├── 바이브코딩.md
└── GitHub_Projects_일정관리_공유/
    ├── README.md            ← 묶음 안내
    ├── 사례와_세팅.md        ← BusDrive 사례와 세팅 여섯 단계
    ├── Skills_메뉴얼.md      ← BusDrive 팀 커스텀 스킬 사용법 (참고용)
    ├── 스킬_템플릿/          ← /task, /backlog, /todo 스킬 템플릿
    └── Image/               ← 화면 캡처
```

> 사례는 BusDrive 프로젝트 팀의 실제 운영 기록이다. 공개용으로 팀원 계정과 이름은 가려 두었다.
