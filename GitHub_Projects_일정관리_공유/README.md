# GitHub Projects + Claude Code 일정 관리 — 공유 묶음

GitHub Projects 보드를 Claude Code 스킬로 운영하는 방식을 다른 프로젝트에서도 쓸 수 있게 묶은 폴더다. 사례 소개, 세팅 방법, 바로 설치할 수 있는 스킬 템플릿이 들어 있다.

**전제**: 팀이 Claude Code를 쓰고, 코드가 GitHub 저장소에 있다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| [사례와_세팅.md](사례와_세팅.md) | 어떤 구성인지, BusDrive에서 어떻게 쓰는지, 같은 환경을 만드는 여섯 단계, 겪은 함정 |
| [스킬_템플릿/](스킬_템플릿/README.md) | `/task`, `/backlog`, `/todo` 스킬에서 팀 정보를 뺀 것과 작업일지 양식 |
| [Skills_메뉴얼.md](Skills_메뉴얼.md) | BusDrive 팀이 실제로 쓰는 커스텀 스킬 10개의 사용법 (참고용) |
| `Image/` | 사례 문서에 쓰인 화면 캡처 |

## 쓰는 법

1. **이 폴더를 통째로 자기 저장소에 넣는다.** 위치는 아무 곳이나 된다(예: `Docs/`).
2. **[사례와_세팅.md](사례와_세팅.md)의 1~2절을 읽는다.** 무엇을 만들게 되는지 먼저 본다.
3. **3절의 여섯 단계를 순서대로 한다.** 단계마다 Claude Code에 붙여 넣을 요청문이 있다. 저장소 루트에서 Claude Code를 열고 이렇게 시작하면 된다.

   ```
   Docs/GitHub_Projects_일정관리_공유 폴더의 사례와_세팅.md 와 스킬_템플릿/README.md 를 읽어줘.
   우리 저장소 <주인>/<저장소> 에 이 문서의 일정 관리 환경을 만들 거야. 1단계부터 같이 진행하자.
   ```

4. **세팅이 끝나면 이 폴더는 지워도 된다.** 실제로 쓰이는 것은 `.claude/skills/`에 설치된 스킬이다.

## 알아 둘 것

- 스킬 템플릿은 그대로 쓰는 완성품이 아니다. `{{...}}` 자리에 팀 값을 넣어 설치해야 동작한다. 그 작업은 Claude가 한다.
- 세팅 단계의 요청문은 빈 저장소에서 처음부터 돌려 본 것이 아니다. 막히면 사례 문서 4절의 함정을 먼저 본다.
- 스킬은 Windows에서만 써 봤다. macOS에서 고칠 곳은 [스킬 템플릿 README](스킬_템플릿/README.md)의 "주의"에 있다.
- 디스코드 알림, 스크린샷 첨부, 작업일지는 각각 빼고 쓸 수 있다.
